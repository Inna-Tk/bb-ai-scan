# AI-Readiness Audit — landing prototype

Прототип посадочной страницы для Digital Construction Day (13 октября 2026, Brussels Gate).
Переход по QR со стенда 51.

**Живая версия:** https://inna-tk.github.io/bb-ai-scan/

## Устройство

Четыре шага. Контакт сохраняется на первом — до вопросов и календаря,
чтобы лид не терялся, если человек бросит страницу на середине.

1. Оффер и контактные данные
2. Два квалифицирующих вопроса
3. Выбор слота на 10-минутный звонок
4. Подтверждение

## Что заменить перед запуском

- Имя и телефон того, кто звонит (сейчас заглушка)
- Ссылка на запись кейса с клиентом
- Ссылка на политику обработки данных
- Отправка формы в HubSpot
- Перевод на нидерландский
